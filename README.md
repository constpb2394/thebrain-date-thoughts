Консольная команда для создания Мыслей с типом Дата в [Цифровом Уме (заметки, приложения, связи)](https://thebrain.com/) с помощью TheBrainAPI

## Проблема
Я использую TheBrain для ведения личного дневника и структуризации своих Мыслей. Мне необходимо создавать ноды на каждый *день* на каждый *месяц*
с именами в формате [номер_дня] [название_месяца] [год] и связывать их все с нодой с именем в формате [название_месяца] [год] для структуризации ежедневных записей.
Мне потребовалось создавать такие ноды на месяц вперёд для планирования своих Мыслей. Также мне стало необходимо к каждой ежедневной мысли прикреплять тип Мысли - нода с именем Дата,
и прикреплять тэг соответсвующего дня недели.

Я создал консольную команду на базе PHP-фреймворка Symfony и несколько сервисов и покрыл юнит-тестами.

## Использование

### Конфигурация
Для работы команды необходимо в `.env` указать следующие переменные:
* `THEBRAIN_API_URL` - URL TheBrainAPI (есть возможность запустить локальный API)
* `THEBRAIN_API_KEY` - ключ аутентфикации TheBrainAPI
* `BRAIN_ID` - идентификатор Мозга
* `DATE_TYPE_THOUGH_ID` - идентифкатор ноды Дата
* `MONDAY_TAG_ID` и другие - индетификатор тэгов с именами дней недели

### Запуск
вызвать консольную команду `date:create [month_number] [parent_thought_id]`
* `month_number` - номер месяца от 1 до 12
* `parent_thought_id` - идентификатор ноды с именем в формате [название_месяца] [год] для связи в качестве родительской для созданных нод
